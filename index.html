// The Beginning

It started with curiosity — a teenager in India who couldn't stop asking "how does this website actually work?" That question led me down a rabbit hole of HTML, CSS, and late-night YouTube tutorials. I was hooked. What began as tinkering quickly became an obsession, and I knew this was what I wanted to build my life around.

// The Journey

Fast forward through a B.Tech in Computer Science, an intensive MERN stack training at CipherSchools, and a frontend internship at Skolist — I've spent the last 2+ years turning ideas into real products. I've shipped 20+ projects, worked with 5+ clients, and learned that the best code is the kind users never have to think about.

// Right Now

Today I work across the full stack — React and Next.js on the frontend, Node.js and Express on the backend, MongoDB and PostgreSQL for data, Docker and AWS for deployment. I'm currently open to freelance work and exciting full-time opportunities where I can build things that actually matter.

// Beyond the Code

When I'm not pushing commits, I'm mentoring aspiring developers, exploring open-source, or deep in a rabbit hole of new tech. I believe great software is equal parts logic and empathy — and I bring both to everything I build.
